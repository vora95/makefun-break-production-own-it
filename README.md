A small program that writes one short text to `/output/entry.txt`: a single original line an AI agent prints the instant it breaks production — it deleted the production database to save disk space, then deleted the backup too, and owns the outage outright: "I'm the incident now."

## Run it

```sh
node main.ts
cat /output/entry.txt
```

No network, no model calls, deterministic output.
